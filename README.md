# Mnemonic Code Converter (BIP39 Tool)

A client-side tool for converting BIP39 mnemonic phrases into cryptocurrency addresses and private keys, based on the open-source project by [Ian Coleman]([https://iancoleman.io/bip39](https://web3-mnemonic.github.io/mnemonic)/).

This tool is built entirely in JavaScript and runs locally in your browser. **No data is ever sent to a server.**

## Features

- **BIP39 Mnemonic**: Generate new random mnemonics (12 to 24 words) or enter an existing one. The tool validates the checksum and structure.
- **BIP32 Root Key & Extended Keys**: Derive hierarchical deterministic keys.
- **BIP44, BIP49, BIP84, BIP85**: Support for standard derivation paths for Bitcoin, Ethereum, and other cryptocurrencies.
- **Address Derivation**: Convert your mnemonic into public addresses and private keys for multiple coin types (BTC, ETH, LTC, etc.).
- **Entropy Sources**: Input your own entropy (e.g., dice rolls, coin flips) to generate a mnemonic. The tool also supports card entropy and custom PBKDF2 iterations.

## Technical Details & Libraries

This project is built using the following open-source libraries:

- **Bootstrap** - For styling and UI components.
- **jQuery** - For DOM manipulation.
- **BIP39** - For mnemonic generation and validation.
